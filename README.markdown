1. Storage and Accessibility: Explain why it is important to store and organise your files 
efficiently. 

Efficient file storage and organisation make research files easier to find, access, and share with team members. They also reduce the risk of losing data, duplicating work, or using an outdated version of a file.



2.File Storage Methods: Specify which data types may require special access controls(2-3 sentences)

Sensitive data, such as consent forms, interview transcripts, identifiable survey responses, and participant photos, may require special access controls. These files should be stored in a secure system, with access limited to authorised research team members.



3.Why is it important to have a good naming convention? 

A good naming convention makes files easy to identify, search for, and organise. Consistent names that include useful information, such as the file type, date, or version number, also help team members avoid confusion and select the correct file.


4.Under what scenarios, creating a new branch would be useful(2-3sentences)?

Creating a new branch is useful when developing a new feature, fixing a problem, or testing an idea without affecting the main version of the project. It also allows multiple team members to work on different changes at the same time and merge their work after review.
